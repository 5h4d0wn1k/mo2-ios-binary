# Contributing

Thanks for your interest in contributing. This project is for education and authorized security research.

## Guidelines

- Keep the project dependency-free (Python standard library only).
- Follow the existing code style; do not add unnecessary comments.
- Add or update unit tests in `tests/` for any change.
- Verify with `python3 -m pytest -q` before submitting.
- Do not include real credentials, keys, or personal information in code or docs.
- This tool is for authorized use only. Do not contribute features that bypass authorization controls.

## Process

1. Fork the repository and create a feature branch.
2. Make focused changes with clear commit messages.
3. Ensure all tests pass.
4. Open a pull request describing the change and its motivation.
